# Locked series editorial principles

Consulting-led **and** genuinely educational. Include the concepts necessary to understand technology decisions: architecture, how mechanisms work, limitations, alternatives, and why we choose or reject a service. The target audience is UK/European/US engineering leads and executives plus engineers learning how consulting is performed. Duration and number of episodes are flexible; depth and credibility win over speed.

The previous standalone 24-episode Kubernetes Networking calendar remains separate and unchanged.
