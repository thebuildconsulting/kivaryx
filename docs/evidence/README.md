# Evidence and truth classification

Use **STORY** (fictional company assumption), **OBSERVED** (test or configuration evidence), **INFERRED** (reasoned but not validated), **PROPOSED** (candidate change), and **MEASURED** (quantitative tested outcome with sample size and run metadata).

Evidence files MUST record source SHA, test scenario, command, host/tool versions, timestamp, controlled test inputs, expected vs actual and limitations. Never commit secrets, PII, raw payment details or real data. Create a report only after checking every finding against evidence.
