# Integration with THE BUILD website (separate repository)

The company repo is **source + evidence**; `thebuildwebsite` remains **commercial site and CRM**. Never copy the Supabase CRM, real leads, form data or credentials here.

For each episode, produce publishing metadata (draft structure in `publication/series.yaml`):
- fictional company display name and synthetic disclaimer
- playlist/series slug, episode number, episode slug, primary problem, educational topics
- approved diagrams/reports/technical evidence, tool versions
- Git release tag/SHA, YouTube URL and report download URL when available
- consulting CTA category (e.g. cloud assessment, payment reliability, security), NOT invented testimonials

Website should expose separate `Engineering Labs` for fictional projects and `Use Cases` for authorised real engagements, both connected to `Request an Infrastructure Review`. Attribution and lead capture happen on website only.
